# NOVA AI

**Персональный ИИ-ассистент на Python · macOS · AI-assisted development**

Личный проект Сергея Бертова: работа с языковыми моделями, памятью ассистента, голосом и инструментами автоматизации. Код развивается с помощью Claude и OpenCode; мой вклад — постановка задач, запуск решений, проверка поведения и обратная связь по ошибкам.

> Это исходный код для ознакомления и презентации. Снимок не сертифицирован как безопасный, не является готовым установщиком и не проходил в этой среде функциональную проверку на macOS. Для просмотра проекта запуск не нужен.

## Направления проекта

- Обращение к нескольким LLM-провайдерам и обработка ошибок запросов.
- Контекст разговора, обычная и семантическая память.
- Работа ассистента с инструментами и подтверждением действий.
- Текстовое и голосовое взаимодействие.
- Интеграции с Telegram и локальными возможностями macOS.

## Пример инженерной задачи

Изоляция тестов семантической памяти от реальных данных: временные каталоги, общий экземпляр памяти, конфигурация и отсутствие побочных записей при импорте. Связанные сценарии находятся в `tests/test_memory.py` и `tests/test_semantic_memory*.py`.

## Требования и ограничения запуска

Проект ориентирован на **macOS**: зависимости `pyobjc-*`, AppleScript и системные интеграции не делают его кроссплатформенным. Совместимость конкретной версии Python и полного набора зависимостей в этой проверке не подтверждена. Корневой `requirements.txt` может не покрывать все опциональные режимы.

После самостоятельной проверки зависимостей, в отдельной тестовой учётной записи или виртуальной среде macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
# Изучите SECURITY.md, .env и config.py перед следующим шагом.
python main.py
```

Это инструкции из структуры проекта, а не отчёт об успешном запуске. Установку зависимостей и приложение при подготовке публичного снимка не запускали.

### Конфигурация демонстрационной копии

В `.env.example` выбран текстовый режим; отключены Telegram-бот, автоматический подбор публичных прокси, фоновое самообучение, экранный контекст и распорядок дня. Реальных API-ключей нет. Это настройки шаблона, а не гарантия полного отсутствия сетевых запросов или системных действий. Без копирования шаблона в `.env` код может использовать другие значения по умолчанию — см. `config.py`.

### Голосовые модели

Большие веса Vosk, Piper и Kokoro, включая вложенные дубликаты, исключены из репозитория. Исходный архив содержал примерно 1 ГБ распакованных файлов, преимущественно весов моделей. Подробности — в `docs/MODELS.md`. Не скачивайте и не распространяйте сторонние веса без проверки их лицензий.

## Тесты

В проекте есть сценарии для памяти, разрешений, провайдеров, инструментов и интеграций. Перед запуском изучите `tests/conftest.py` и конкретные тесты: часть сценариев может обращаться к сети, локальным файлам или системным функциям.

При подготовке публикации выполнен только статический разбор синтаксиса Python. Запуск `pytest`, GUI, интеграций и внешних API не выполнялся. Старые количества passed/failed из исторических документов не относятся к этой проверке.

## Безопасность и приватность

Приложение содержит функции управления приложениями, работы с почтой, Telegram, микрофоном, снимками экрана и пользовательскими данными. Вызовы к LLM и TTS могут передавать текст внешним провайдерам. Изучите [SECURITY.md](SECURITY.md) перед запуском. Для презентации предпочтительны просмотр кода и заранее подготовленная демонстрация на тестовых данных.
