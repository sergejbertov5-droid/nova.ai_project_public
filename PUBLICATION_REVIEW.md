# Проверка перед публикацией

## Объём проверки

Проверена отдельная копия присланного архива. Исходный ZIP не изменялся. Код, зависимости, приложение и тесты не запускались.

- Структура ZIP: 242 записи, около 1.019 ГБ после распаковки; обходящих каталог путей и символических ссылок не обнаружено.
- Проверены доступные UTF-8 текстовые файлы; регулярные выражения искали типовые API-токены, Telegram bot tokens, приватные ключи, литералы учётных данных и локальные пути пользователей.
- В текстовом анализе реальных ключей не выявлено. Совпадения формата провайдерских ключей находились в тестах; для публичной копии 8 различных строк заменены явными синтетическими TESTONLY-значениями. Это может требовать корректировки отдельных тестовых ожиданий; тесты после замены не запускались.
- Поля ключей, аккаунтов и идентификаторов голоса в `.env.example` очищены. Идентификаторы Telegram установлены в 0, остальные чувствительные значения пусты.
- Python AST: 145 файлов разобраны без синтаксических ошибок; это не проверка импортов, зависимостей или поведения.
- Исходники содержат сетевые интеграции, управление macOS, LaunchAgent, снимки экрана и операции с данными. Для них добавлен SECURITY.md; полная проверка защиты этих операций не выполнялась.

## Изменения публичной копии

- Удалены из поставки сторонние веса моделей и их вложенные дубликаты. Лицензирование весов отдельно не проверялось.
- Сохранены исходники, тесты, конфигурационные шаблоны и исходная MIT-лицензия.
- Переписан README для презентации; исходный README сохранён в docs/LEGACY_README.md с предупреждением о непроверенных исторических утверждениях.
- Демонстрационный .env.example переведён на текстовый ввод с отключёнными отдельными фоновыми функциями; production-defaults в config.py не менялись.
- Усилен .gitignore для секретов, памяти и локальных артефактов.

## Ограничения

Это ограниченная статическая проверка и подготовка к ознакомительной публикации, не сертификация безопасности. Регулярные выражения не находят все возможные секреты. Поведение macOS, права доступа, зависимости, уязвимости, сетевые действия и тесты должны проверяться отдельно. Просматривать исходники можно без их запуска. Для передачи готового запускаемого приложения этой проверки недостаточно.
